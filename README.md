# Arc-en-ciel Creator（アルカンシエル・クリエイター）

モンスターをマス目に置いて資材を集め、施設を建てて敵の波を防ぐタワーディフェンス。融合と錬成でモンスターを集めて育てる。

**遊ぶ：** https://stm28355-ux.github.io/arc-en-ciel-creator/

今は仮版です。第1地方の「草原」と、モンスターの錬成・図鑑・レベルアップ・融合・進化が遊べます。

## 遊び方

0. 「モンスター」→「錬成」で、最初にもらった無のエレメントから仲間を作る（エレメントの配合で生まれるモンスターが変わる）
1. 「モンスター」からモンスターを選び、草地のマスに置く。R キーか「回転」で向きを変える（攻撃は向いている方のマスに届く）
2. 資源地（◆）のとなりや攻撃範囲に置くと資材が入る
3. 「建設」で資材を使って施設を建てる（鍛冶場にモンスターを付けると剣の台座が建てられる）
4. 「戦闘開始」で5つのウェーブを防ぐ。拠点の耐久が0になるか、ボスを通すと負け（失うものはない）
5. 攻略すると獲得ペースが記録され、その地域からエレメントが自動で入り続ける
6. 手に入れたエレメントで、新しい仲間を作ったりレベルを上げたりして、また挑戦する
7. 2体を融合すると、系統と位階で決まる新しいモンスターが生まれ、親の技を引き継げる（技は最大3つ）。特別な組み合わせでだけ生まれるモンスターもいる。条件を満たしたモンスターは進化できる

## 開発

```bash
npm run serve   # http://localhost:5180/
npm test        # テスト
npm run sim     # 草原を画面なしで流して、見本の配置の結果を出す
```

ビルドはありません。`index.html` と `src/` がそのまま GitHub Pages で動きます。
