## 名前

- 英語：**Arc-en-ciel Creator**（Creater → Creator に直した。arc-en-ciel はフランス語で「虹」）
- カタカナ：**アルカンシエル・クリエイター**
- 9属性を虹にたとえて、属性の色は虹の並びを意識している

## 作り方

| 項目 | 決めたこと |
|---|---|
| 形 | 静的HTML＋JavaScript（ESモジュール）。ビルドなし。`index.html` を開けば動く（ローカルでは `npm run serve`） |
| 描画 | 地域マップは canvas、パネルは HTML |
| セーブ | ブラウザの localStorage（端末ごと） |
| テスト | `npm test`（Node の標準テスト）。戦闘・生産・建設は画面と分けて、テストできるようにする |
| 確認の道具 | `npm run sim`：地域を画面なしで最後まで流して、勝ち負け・時間・獲得ペースを出す |
| 公開 | GitHub Pages（main ブランチの一番上のフォルダ）。push すると数分で反映 |
| 進み具合 | GitHub の Milestones ＝ フェーズ、Issues ＝ やること・未決事項。この計画書の表も更新する |

## 変えないこと（企画まとめから）

- 生産・建設・戦闘は1枚の地域マップで行う。別画面にしない
- 資材は時間で貯まらない。配置で決まる固定の量。地域マップの外へ持ち出さない
- 資材が足りなくなったら、足りない施設のうち最後に建てたものが止まる
- モンスターも施設も戦闘で失わない。負けたらウェーブ1から、失うものはない
- 拠点の耐久は3から（研究で増える）。ウェーブは一律5
- 獲得ペース ＝ 全ウェーブで得たエレメント ÷ 全ウェーブを通しで倒すのにかかった時間。一時停止中はタイマーが止まる
- 戦闘でのモンスターのドロップはない。入手は錬成だけ
- 9属性：無・風・土・水・雷・炎・氷・光・闇
- 攻撃・効果の範囲はマス目の形。向きで範囲の方向が決まる（フェーズ2で決定）
- 最後のボスを通したら拠点は全損。ボスを倒さないとクリアにならない（フェーズ2で決定）
- 負けても、その挑戦で得たエレメントは持ち帰る。勝てないときに新しいエレメントで何をするかもサイクルの一つ（フェーズ2で決定）
- 攻略後の自動獲得はページを開いている間だけ。求めるのは放置ではなく、挑戦と改善のサイクル（フェーズ2で決定）
- 戦闘中にモンスターも施設も動かせる。動かしたら攻撃は溜め直し（フェーズ2で決定）
- 製造施設は、作業場所にいて攻撃範囲が施設に重なるモンスターがいる間だけ動く。作業中のモンスターも攻撃と生産をする（フェーズ2で決定）
- 自動で再挑戦の間は速さに上限（2倍）。倍速を見た目だけにする案は、実感がなく不快なので採らない（フェーズ2で決定）
- 角笛で早く負けて稼ぐ周回は、ハック要素としてあえて残す（フェーズ2で決定）

## 周回のペース（Issue #4 の確認）

自動で再挑戦したときに、1周ごとに入るエレメント ÷ 1周の時間（再挑戦までの1.5秒を含む）。

| 配置 | 1倍速 | 8倍速 |
|---|---|---|
| 光線塔＋旗（攻略） | 0.38/秒 | 2.90/秒 |
| 角笛1個（ウェーブ4で負け） | 0.49/秒 | 3.62/秒 |
| モンスター1体（ウェーブ1で負け） | 0.02/秒 | 0.12/秒 |

- 1倍速なら、周回は攻略後の自動獲得（記録したペース）とほぼ同じ。ウェーブ1だけで負ける周回はとても遅い
- **倍速で周回すると、実際の時間あたりは倍速の分だけ速くなる**（8倍速なら約8倍）。自動獲得より速いサイクルになる
- 角笛で早く負ける周回が、角笛なしで攻略するより速い（0.49 > 0.38）。ハック要素として残す
- 決定：自動で再挑戦の間は2倍速まで。周回の実時間あたりの獲得は、攻略後の自動獲得の約2倍まで

## フェーズ3：錬成と育成（v0.3.0、仮）

| 項目 | 仮の決め方 |
|---|---|
| はじめ | 手持ちなし、無のエレメント30。案内に従って調合錬成でプチスライムを作る。1〜2体では草原のウェーブ1を越えられないので、30（3体分）にした |
| 調合錬成 | 第1地方の3属性（無・風・土）を合計10〜60入れる。決め手は「一番多い」「二番目」「種類の数」。同じ量なら無・風・土の順で前を「多い」とする。合計10を超えた分は、レベルアップの値段どおりに生まれるレベルになる（v0.4.0。60入れるとLv8） |
| 特殊 | 比率をぴったり合わせたときだけ。今は「無・風・土を同じ量ずつ」→ にじいろスライム |
| 図鑑 | 一度作ったモンスターが載る。まだのものは「？？？」と、何種類で作るかのヒントだけ出す |
| 図鑑錬成 | 図鑑に載ったモンスターを決まった量（12〜15）で作る。調合より少し高いが、配合を考えなくてよい |

## フェーズ4：融合・技の継承・進化（v0.4.0、仮）

| 項目 | 仮の決め方 |
|---|---|
| 技 | 技＝攻撃（範囲の形・威力・間隔）。モンスターは自分の技を1つ持ち、融合で最大3つまで増やせる。技ごとに別々に攻撃する。威力はモンスターのレベルで伸びる |
| 範囲を使う判定 | 資源地の「攻撃範囲に入る」と鍛冶場の作業は、持っている技の範囲を全部合わせて見る |
| 融合 | 2体を選ぶ（2体は消える）。生まれるのは「特別な組み合わせ」（あれば）「融合のルール」「親1と同じ」「親2と同じ」のどれか。レベルは1。くわしくは下の「融合のルール」（v0.4.2。前の「配合から」は調合と同じになるのでやめた） |
| 技の継承 | 生まれるモンスター自身の技は必ず持つ。親2体の技から、ほかに2つまで選ぶ |
| 進化 | 条件を満たすと、モンスター詳細で進化できる。レベルは1に戻る。自分の技は進化後の技に変わり、引き継いだ技は残る。配置もそのまま |
| 進化したモンスター | 調合では作れない。一度手に入れれば図鑑に載り、図鑑錬成できる（進化前の約3倍の値段） |
| 戦闘の記録 | とどめを刺したモンスターに「倒した数」を数える。剣・旗の効果が乗っていたか、【強】・ボスか、鍛冶場で作業したまま攻略したかも数える |

### モンスターの数の目標（v0.4.2で決めた）

全部で約200体。10系統×20体にする。

| 手に入れ方 | 全体 | 1系統あたり | 第1地方（今） |
|---|---|---|---|
| 調合錬成（1種類9・2種類72・3種類以上9・特殊10） | 100 | 10 | 13 |
| 進化 | 30 | 3 | 6 |
| 融合のルールでだけ生まれる | 60 | 6 | 12 |
| 特別な組み合わせの融合でだけ生まれる（レア） | 10 | 1 | 2 |

- 技の違いは、範囲（重なってよい）・攻撃力・攻撃の間隔に、効果（足止め・まわりにも当たる・毒 など10種類くらい）を足して出す。効果はまだない
- 絵はあとで。系統で体の形、属性で色、位階で飾りを変える「部品の組み合わせ」が候補
- データの量は問題にならない（モンスターのデータは200体で約100KB）

### 融合のルール（v0.4.2、仮）

| 項目 | 決め方 |
|---|---|
| 系統 | モンスターの体の種類。ゲル・プラント・バード・アニマル・ミネラル・ヒュマノ（人型）・マシン・スケイル・テンタクル・レイスの10系統（v0.6.0 でカタカナにそろえた。src/data/families.js だけで変えられる） |
| 位階 | 系統の中での強さの順。調合の1種類＝1、2種類＝2、3種類以上＝3、特殊＝4。進化は進化前＋2。融合でしか生まれないものは3〜5、特別な組み合わせは5〜6 |
| 子の系統 | 同じ系統どうしならその系統。違う系統どうしは表で決める（45通り。src/data/families.js） |
| 子の位階 | 親2体の位階の平均（切り捨て）＋1 |

### 研究の見直し

- 攻撃力の上限 5 → 20、獲得ペース 5 → 10。6から先は第2〜第4地方のエレメントで研究する
- 「戦闘施設の強化」を2つに分けた：「施設の攻撃力」（攻撃とやけど。30まで。段ごとに +20%・+40%・+60%・+80%・+60%、最後は17倍）と「施設の効き目」（剣・旗・ポーション・遅くする・受けるダメージ増。今までどおり5まで +10%ずつ）。1つにまとめたままだと、施設の攻撃力に合わせて上げると剣や旗が強くなりすぎるため
- 施設の攻撃力は、モンスターのレベルと攻撃力の研究の伸び（Lv13で約2.3倍、Lv58で約10.6倍、Lv99で約17.7倍）に、だいたい追いつくようにした。1つの攻撃する施設が、モンスターの技1つ分くらい。はじめ +50%ずつにしたら第1地方で施設が強すぎた（砂漠を Lv1 で攻略できた）ので、段ごとに伸びを変えた
- 大いしゆみを弱くした（風2・無1、攻撃12・2秒ごと → 風3・無2、攻撃10・2.5秒ごと）。安いのに強すぎて、第1地方がモンスターなしで進めてしまうため

### 施設の働き（基準の配置で、その施設を外すと何レベル上がるか）

- よく効く：霧の噴水（+6〜27）、錬金アトリエとポーション（+5〜29）、鍛冶場と剣の台座（+5〜12）、旗（+3〜9）、極限研究所と秘伝書（境界・魔王城で +24〜46）、闇の大時計（+9〜18）、吹雪魔法陣（混成 +12）
- 攻撃する施設は、外しても 0〜4 レベル。第3・第4地方では与えるダメージの1〜7%（仲間が技を3つずつ持つので、施設1つは技40個のうちの1つくらい）
- ほとんど使われない：避雷針（雷3が重く、資材が足りない）、光の鏡、大渦の泉、火矢やぐら。強くするかは企画者と相談
- 資材を取り合って、建てるとかえって弱くなることがある（砂漠の大風車、混成のつららの塔 など）

### 工夫した配置との差（固定する前に企画者と相談）

施設の組み合わせを1つずつ変えて良くする道具（`node tools/tune-facilities.mjs`）で探すと、基準よりかなり低いレベルで攻略できる。旗・秘伝書・つららの塔などを重ねるもの。

| 地域 | 基準 | 工夫した配置 |
|---|---|---|
| 森 / 砂漠 | 8 / 13 | 4 / 7 |
| 川 / 雷雨 / 海 | 20 / 25 / 30 | 16 / 16 / 16 |
| 火山 / 雪山 / 混成 | 35 / 40 / 45 | 29 / 16 / 25 |
| 聖域 / 境界 / 魔王城 | 48 / 50 / 58 | 45 / 20 / 47 |

レベルで強くなるのは1レベルにつき基本の攻撃の+8%なので、Lv40 のころは1レベルで約2%しか強くならない。そのため、施設の効果を重ねて2倍強くなると、20レベル以上の差になる。今は「1種類ずつ建てた人」が目標のレベルで攻略できるように合わせた（工夫する人は早く進める。逆に、工夫した配置に合わせると、1種類ずつの人は上限を超えて詰まる）。重ねられる効果（旗・秘伝書など）を「同じ施設どうしは一番大きいものだけ」にすると差は縮むが、遊びの柱にかかわるので決めていない。

- 工夫した配置との差（上の節。効果を重ねたときの扱い）
- ほとんど使われない施設（避雷針・光の鏡・大渦の泉・火矢やぐら）
- 限界突破 V のレベルアップの値段（60→99 で1体約16500）と、61から先をどのエレメントで上げるか（今はどれでも）
- 研究の値段（拠点の耐久で周回が楽になりすぎないか、持ち込みの資源地で資材が増えすぎないか）
- モンスターごとの強さの差。融合で生まれるモンスターの強さと図鑑錬成の値段
- 進化の条件の重さ

## 頼むときのひな形（auto-battler のふり返りから）

```
■目的：何を作る・直すか
■変えないこと：遊びの柱、決めたルール など
■目標：数字と、その測り方（何を相手に、何回測るか）
■任せてよいこと：数値の当てはめ、シミュレーション、テスト
■必ず確認してほしいこと：遊びの柱にかかわる変更、全体に効く値の変更
■報告に入れてほしいこと：勝ち負け・かかった時間・獲得ペース・使われない施設やモンスター
■締め切り：日本時間 ○月○日 ○時
■説明：やさしい日本語で、結論から
```
